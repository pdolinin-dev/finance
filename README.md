# Система управления личными финансами

Проект реализован как консольное Java-приложение с хранением данных в памяти во время работы и сохранением состояния в JSON-файлы при выходе.

---

## Возможности

- Авторизация пользователей по логину и паролю  
- Поддержка нескольких пользователей  
- Личный кошелёк для каждого пользователя  
- Доходы и расходы по категориям  
- Бюджеты по категориям с контролем лимитов  
- Оповещения о перерасходе бюджета и превышении расходов над доходами  
- Сводная статистика и отчёты  
- Фильтрация отчётов по нескольким категориям  
- Экспорт и импорт состояния кошелька (JSON)  
- Переводы между кошельками пользователей  
- CLI-интерфейс с циклом команд и справкой  
- Unit- и интеграционные тесты  

---

## Требования

- **Java 17+**
- **Maven 3.8+**

Проверка версии Java:
```bash
java -version
```

---

## Сборка и запуск
### Сборка проекта
```bash
mvn clean package
```

### Запуск приложения
```bash
java -jar target/project-1.0.0.jar
```
После запуска откроется интерактивный CLI

---

## Как пользоваться приложением
После запуска приложения пользователь работает с системой через консоль, вводя команды.
Все команды выполняются в цикле до выхода из приложения.

### Поддерживаемые команды
#### Общие команды
```bash
help          — показать справку
exit          — выход из приложения (данные сохраняются)
```
- Авторизация
```bash
register <login> <password>       — регистрация с сохранение логина, пароля
login <login> <password>          — авторизация по логину и паролю
logout                            — выход из аккаунта
```
- Категории
```bash
category add <name>               — создание категории
category rename <old> <new>       — смена названия категории
category list                     — вывод списка категорий пользователя
```
- Бюджеты
```bash
budget set <category> <limit>         — добавление лимита бюджета на категорию
budget edit <category> <newLimit>     — изменение лимита бюджета на категорию
budget list                           — вывод лимитов на категории
```
- Доходы и расходы
Категория должна быть создана заранее.
```bash
income add <category> <amount> [note...]         — создание пополнения для категории
expense add <category> <amount> [note...]        — создание расхода для категории
```
#### Отчёты и статистика
- Общая сводка
```bash
report summary
```
- Доходы и расходы по категориям
```bash
report categories
```
- Фильтрация по нескольким категориям
```bash
report categories --only=Еда,Такси
```
- Бюджеты и остатки
```bash
report budget
```
- Бюджеты и остатки
```bash
report budget
```

#### Переводы между пользователями
```bash
transfer <toLogin> <amount> [note...]
```

#### Экспорт и импорт данных
- Экспорт состояния кошелька
```bash
export json <path>
```
- Импорт состояния кошелька
```bash
import json <path>
```

#### Переключение вывода
```bash
output console
output file <path>
```
